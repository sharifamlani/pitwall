## Concerns (not graded)

1. **Main CI at `852c4c4` has no green run of its own.** The ROADMAP push cancelled it during packaging (`cancel-in-progress` on the `ci-refs/heads/main` group). E1 and E19 lean on `ccb78b4`, whose only diff is ROADMAP.md. Pushing doc-only commits right after a merge will keep doing this.
2. **`dump-tabs.mjs` can read a stale dump.** It treats a dump as live while its pid is alive. During E5 an old dump from 13:20 (pid 23556, now reused by another process) was listed. Its old `sidebarMainChatIds` order came first in the output, so a literal run of the tool's sidebar list against the bound set would have failed for a reason that has nothing to do with the product. I graded on the current window's dump (pid 59864). Suggestion: check that the dump's `pid` belongs to a Cursor/Code process, or delete dumps when the window closes.
3. **E5's measure and terminal chats.** The dump records terminal-surface chats with `sessionId: null`, so "bound tabs" can never include them. A repo with terminal chats can't reach an exact match by the literal measure. I counted the 3 terminal chats through their `route` lines and `Pitwall: <title>` tabs.
4. **Tabs that stay unknown.** A restored "Claude Code" (default title) tab and a tab with a shared title ("Lab ready") stay unbound and unmarked by design (I1b). That is correct under the no-guessing rule, but such chats never show ` · open`. The I1b known issue belongs in the release notes (PR #53 lists it).
5. **E16 window count.** The brief capped my spot-checks at 3 windows, but the criterion asks for ≥ 3 *other* windows. On merged code, only 2 starts were taken inside that condition (r2: 0.614 and 0.653 s). All 17 merged-code starts outside it were ≤ 1 s except the single 4.12 s first-relaunch start, which did not reproduce.
6. **Developer tab dump.** `pitwall-dump/<pid>.json` holds tab labels (chat titles) and is not covered by `--check-privacy`. It is written only by a hidden developer command and is documented in `docs/privacy.md`.
7. **Unnamed lab terminals.** The uj-lab-a window carries 3 `powershell` editor terminals left from earlier walks (names lost on relaunch, per ADR 0009). They are not identified as chats, which is expected.
